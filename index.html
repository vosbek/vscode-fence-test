VS Code, mapped by the software factory

This fork of VS Code has the software factory installed: a codebase map an agent reads before it edits, rules every change is checked against, and C4 diagrams drawn from the map. These are read-only copies of all three, built from the fork's own files.

This is a static copy. Asking questions on the map runs Claude Code on your own machine, so it needs a clone: from a checkout of the factory/onboard branch, run python3 .cartographer/bin/ask.py.

Codebase map

An expandable C4 map of the code

It opens at the system context. Expand the system to see its 21 components by layer, then expand any component to see its folders and files.

  • Wires come from real imports and the edges the map declares.
  • Changed, New and Hotspot badges come from git history.
  • Search with / opens the boxes down to any file.
  • Its Guardrails page lists every guardrail: 21 rules in force (17 block, 4 warn), 16 still proposed, and the 13 checks the fence runs on every pull request. The rules come from VS Code's own guidelines and from its history and map; the owner chose which to put in force.
